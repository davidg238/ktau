# ktau — tap, speak, act

A bring-up of [Toit on Zephyr](https://github.com/davidg238/ztoit) on a board it has never seen, the Seeed XIAO
nRF54L15 Sense: tap it, speak a short instruction, and an LLM acts on it. Built as a ladder of rungs, each with a
demo and a journal entry.

- Design: `docs/design/2026-11-19-ktau-design.md`
- Journal, one entry per rung: `docs/journal/`
- The Toit app: `app/`
